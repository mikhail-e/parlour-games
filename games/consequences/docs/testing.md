# Тесты

Общие правила тестов игр на ядре — `packages/room-kit/docs/testing.md`: команды, два вида тестов, проекты Playwright, игроки и страховка, помощники ядра, сокет комнаты в тестах, правила набора, отладка, прогон против прода. Здесь — своё у Consequences.

## Команды

Из папки игры, `games/consequences/` (из корня — `-w games/consequences` для скриптов npm).

```bash
npm test                                   # всё: ESLint, Jest, Playwright
npx jest tests/game-logic.test.js          # один файл Jest
npx playwright test tests/e2e/writing.spec.js --project=desktop   # один файл в одном проекте
```

## Что проверяют тесты по тексту файлов

- `code-structure.test.js`: ни `style="..."`, ни `on...="..."` в страницах и скриптах игры (`inlineCodeProblems` ядра);
- `shared-names.test.js`: общие имена скриптов страниц — игры и ядра вместе (`sharedNameProblems` ядра);
- `translations.test.js`: оба языка словаря, одинаковые подстановки, словарь не повторяет тексты ядра, у каждой ошибки сервера есть русская копия (`translationProblems` ядра);
- сверка копий, которые игра держит намеренно: предел ответа в `game-logic.js` и в `utils.js` (`input-limits.test.js`), три копии вывески (`brand-sign.test.js`).

## Серверы тестов

Playwright запускает два `wrangler dev` (`playwright.config.js`):
- на порту 3200 — обычный, для всех тестов;
- на порту 3201 — с короткими таймерами комнаты (`ROOM_EMPTY_MS: 8000`, `GHOST_MS: 3000`): на нём идёт только `room-timers.spec.js` (`test.use({ baseURL: process.env.E2E_FAST_TIMERS_URL })`).

Порты whoami — 3100 и 3101, так что прогоны двух игр не встречаются; запущенный `npm start` (8788) тоже не мешает.

## Помощники (`tests/e2e/helpers.js`)

Файл передаёт дальше помощники ядра (`packages/room-kit/docs/testing.md`, Помощники ядра: тексты страниц, вход, создание комнаты, выход, новичок, медленная связь…) и добавляет свои — для раунда. Ответ по умолчанию называет автора и шаг: «Anna 3» — ответ Ани на третий вопрос, так что по истории видно, какое место что написало.

| Помощник | Что делает |
|---|---|
| `text(ключ, язык, подстановки)`, `serverErrorText(текст, язык)` | тексты `translations.js` игры поверх текстов ядра (`pageTexts` ядра) |
| `startRound(игроки)`, `startedRound(newPlayer, имена)` | «Начать» у первого и ожидание первого вопроса у всех; целая комната с начатым раундом |
| `answer(игрок, текст)` | ответ в поле и «Загнуть и передать» |
| `answerStep(игроки, шаг, ответ?)` | каждый отвечает на вопрос шага, ожидание следующего шага у всех |
| `writeToReading(игроки, ответ?)` | все восемь шагов: раунд дошёл до чтения |
| `waitForStep(игроки, шаг)`, `roundStep(страница)` | шаг раунда, каким его знает страница (`currentGame.round.step`: 0–7 вопросы, 8 чтение, `null` в лобби) — на любом языке |
| `returnToRound(игрок, код)` | возврат в идущий раунд по ссылке: главная, имя, «Войти» — и стол раунда, а не лобби (`joinRoom` ядра ждёт карточку лобби) |
| `seatRow(страница, имя)` | строка стола с этим именем (своя — «Имя (Вы)») |

## Особые тесты

- **Тайна ответов**: `secret.spec.js` читает каждое сообщение, которое получают сокеты страниц, и ходит ходами страницы (`sendMove`), а не кнопками: ему важно, что уходит по сети, а не что видно.
- **Гонки**: «Ответить за» у двоих сразу (`writing.spec.js`) — лист достаётся одному, другой видит, кто пишет, и никакого окна с ошибкой: проигранная гонка — не сбой (`LOST_RACES` в `game-room.js`).
- **Экран не гаснет**: `writing.spec.js` спрашивает настоящий Chromium с разрешением `screen-wake-lock` и оборачивает `navigator.wakeLock.request`, чтобы видеть выданные блокировки. Подмена браузера с отказами и скрытой страницей — у whoami (`wake-lock.spec.js`): это поведение ядра.
- **HTTP API**: `api.spec.js` — без страницы, только в проекте `desktop`.
- **Журнал игры** в консоли теста: `await player.page.evaluate(() => localStorage.setItem('consequences-debug', 'on'))` и перезагрузка.
