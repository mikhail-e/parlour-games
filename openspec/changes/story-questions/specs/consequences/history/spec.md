# Spec Delta

## MODIFIED Requirements

### Requirement: Окно «Все истории»
Окно SHALL показывать один раунд: заголовок называет истории его набора («Все детективы»), строка под ним говорит «Раунд N из M», ниже каждая история раунда целиком, с номером словами, именем прочитавшего, вопросом мелким текстом в цвет игры над каждым ответом и «Поделиться историей». Вопросы SHALL быть из набора показанного раунда. Раунды SHALL нумероваться по порядку игры, считая только раунды истории и текущий раунд чтения. Окно SHALL закрываться крестиком.

#### Scenario: Раунд в окне
- **WHEN** игрок открывает окно на втором раунде, «Детективе», из трёх
- **THEN** он видит заголовок «Все детективы», строку «Раунд 2 из 3», под ней «Детектив первый», «Детектив второй» и так далее, с именами прочитавших

#### Scenario: Вопросы прошлого раунда
- **WHEN** игрок листает окно с текущего раунда, «Детектива», назад на прошлый, «Сказку»
- **THEN** над первым ответом каждой истории прошлого раунда стоит «Жили-были… кто?», вопрос «Сказки», а не «Где?» «Детектива»

#### Scenario: Поделиться историей прошлого раунда
- **WHEN** игрок нажимает «Поделиться историей» у истории прошлого раунда со «Сказкой»
- **THEN** сообщение начинается с названия набора этого раунда, «★ СКАЗКА ★», а не набора последнего раунда
