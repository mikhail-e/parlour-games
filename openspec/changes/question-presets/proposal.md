# Proposal

## Why

В «Чепухе» один список вопросов, и каждый раунд идёт по нему. Компания, которая сыграла несколько раундов подряд, начинает писать одно и то же. Владелец хочет разнообразия: несколько наборов вопросов, и в начале каждого раунда случайно выпадает один из них. В основу взяты классические вопросы «Чепухи».

## What Changes

- **Семь наборов по восемь вопросов**, по-русски и по-английски, согласованные с владельцем:
  - варианты классики: «Классика» (нынешний список, без изменений), «Случай» (кого-то застали, назван по циклу Хармса), «Он и она» (английская классика);
  - темы на скелете классики: «Сказка», «Детектив», «Новости», «Путешествие».
  Тексты всех наборов — в дельте спека `consequences/writing`.
- **Один набор на весь раунд.** В начале раунда сервер выбирает набор случайно, и все игроки отвечают на один и тот же вопрос, как сейчас.
- **Набор не выпадает два раунда подряд**: следующий раунд выбирает из остальных шести. Комната помнит прошлый набор, пока жива.
- **Игроки видят набор в заголовках.** При письме заголовок листа — название набора. Остальные заголовки раунда называют истории набора вместо «истории»: «Сказку рассказывают», «Сказки готовы», «Все сказки», «Сказка первая». У «Классики» они прежние. История, которой делятся («Поделиться историей»), начинается с названия набора.
- В каждом наборе восемь вопросов. Число шагов, отметки шагов, «Вопрос N из 8», чтение и пауза не меняются.
- Правило на главной странице («Восемь вопросов: кто, с кем…») перестаёт перечислять вопросы одного набора и говорит о наборах. То же в README игры и репозитория.
- Хранилище комнаты не меняется: раунд, сохранённый прежней версией и проснувшийся на новой, читается как «Классика».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `consequences/writing`:
  - «Восемь вопросов»: восемь вопросов набора раунда, а не одного списка, и сами наборы;
  - «Начало раунда»: первый вопрос — вопрос набора;
  - «Листы сдвигаются, когда ответили все»: в примере назван вопрос набора;
  - новые требования: «Набор вопросов раунда» (случайный выбор без повтора подряд), «Набор в заголовках при письме», «Истории набора» (слово набора вместо «истории») и по требованию на каждый набор с его вопросами.
- `consequences/reading`:
  - новое требование «Набор в заголовках при чтении»: заголовки чтения и историй по набору, название в начале истории, которой делятся;
  - «Все истории»: кнопка и заголовки историй со словом набора, в примере «Поделиться историей» текст начинается с названия набора.

## Impact

- **Сервер** (`games/consequences/game-logic.js`): список наборов, выбор при старте раунда, набор в раунде и в том, что получают страницы (`roundView`), прошлый набор в игре. Протокол сокета прежний: в состоянии раунда появляется одно поле.
- **Страницы**:
  - `public/js/translations.js`: названия, вопросы и заголовки наборов на обоих языках; прежние ключи вопросов и заголовков становятся ключами «Классики»;
  - `public/js/game-room.js`: вопрос, складки и заголовки по набору раунда;
  - `public/game.html`, `public/css/style.css`: заголовок листа при письме и строка «Лист Веры» под ним;
  - `public/index.html`: правило о вопросах.
- **Тесты**:
  - Jest (`game-logic.test.js`, `translations.test.js`): выбор набора, без повтора подряд, раунд прежней версии, тексты каждого набора;
  - Playwright: тесты, которые ждут текст вопроса, берут набор раунда по его названию на странице, поэтому тот же набор тестов идёт и против прода; новые тесты на название и смену набора.
- **Документы**: CLAUDE.md игры (раунд, страница комнаты), README игры и корневой README. Черновик `games/consequences/docs/question-presets.md` уходит: таблицы переезжают в спек, тексты — в `translations.js`.
- **Выпуск**: этот change трогает только Consequences (минорная версия), ядро и whoami не меняются. Но ближайший выпуск поднимет и whoami: в `develop` уже лежит правка кнопки «Скопировать» в её приглашении.
