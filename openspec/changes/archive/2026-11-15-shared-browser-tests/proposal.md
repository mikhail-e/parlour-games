# Proposal

## Why

Поведение ядра проверяют браузерные тесты каждой игры на её страницах (решение владельца, `packages/room-kit/CLAUDE.md`), но сами тесты написаны дважды: целые spec-файлы и десяток тестов скопированы из whoami в Consequences почти слово в слово. Копии уже разошлись (страница 404 whoami не проверяет вывеску, `site.spec.js` whoami не проверяет иконки манифеста и регистрацию service worker), а правило игр «никакого дублирования кода между файлами» (`CLAUDE.md` каждой игры, правило 2) тесты нарушают. Ревью тестов нашло и лишние прогоны: запросы без страницы идут на телефоне и на компьютере, хотя устройство на ответ сервера не влияет, а против прода каждый лишний запрос расходует дневной лимит Cloudflare.

## What Changes

- Новый файл ядра `packages/room-kit/e2e-kit-tests.js`: общие браузерные тесты, которые игра запускает на своих страницах и своих настройках одной строкой, как уже запускает `e2e-check-tag.js`. Группы по частям ядра:
  - главная страница (`landing.js`): ссылка на несуществующую комнату, имя и аватар запоминаются после создания и после входа, два игрока с одним именем, фото вместо эмодзи видят все;
  - страница комнаты (`room-page.js`, `invite.js`): выход из лобби, Leave в одной вкладке выводит из всех, последний вышедший удаляет комнату, Copy Link;
  - таймеры комнаты (`game-room.js`): комната без открытых страниц уходит, пока все страницы закрыты, никто не уходит;
  - сайт (`http.js`, `_headers`, `pwa.js`): ничего с чужих сайтов, заголовки безопасности на каждом адресе, версия внизу страниц, иконки, service worker, «Update now»;
  - страница 404;
  - карточки превью ссылки, `robots.txt`, `llms.txt` (название игры передаётся параметром).
- Тесты, которые сейчас есть в обеих играх, удаляются из игр: игра вызывает группу ядра в файле той же темы. Где копии разошлись, общая версия берёт обе проверки.
- Общие помощники браузерных тестов переезжают в `packages/room-kit/e2e-helpers.js`: имена игроков в списке (`listedNames`), плитки аватаров (`avatarTiles`), проверка axe (`axeViolations`), пауза для тестов таймеров (`sleep`).
- Тесты без страницы (только запрос к серверу и разбор ответа) идут в одном проекте Playwright, `desktop`, как `api.spec.js`.
- В тесте «комната без открытых страниц уходит» пауза на 9 секунд заменяется ожиданием условия: тест спрашивает адрес комнаты, пока тот не ответит переадресацией на главную.
- Удаляются тесты, которые повторяют другие тесты и ничего к ним не добавляют: юнит-тест i18n ядра, запущенный в браузере (`games/whoami/tests/e2e/language.spec.js`: «an unknown text key shows the key itself», «an unknown language falls back to English»), и полный раунд на двух игроках в `games/consequences/tests/e2e/reading.spec.js` (правило «читает лист соседа» для двух игроков проверяет Jest `test.each`, отрисовку листа проверяет тест на трёх игроках).

Для игроков не меняется ничего: код страниц, сервера и комнат не трогается.

## Capabilities

### New Capabilities

Нет. Change меняет только тесты, поведение игр не меняется, поэтому спеки не пишутся (`skip_specs: true`), как в room-kit.

### Modified Capabilities

Нет.

## Impact

- **Ядро**: новый `e2e-kit-tests.js`; `e2e-helpers.js` получает четыре помощника; `CLAUDE.md` ядра (раскладка, Playwright) и `docs/testing.md` (общие тесты ядра, помощники, правило о запросах без страницы).
- **whoami** (`games/whoami/tests/e2e/`): `landing.spec.js`, `site.spec.js`, `site-headers.spec.js`, `not-found.spec.js`, `link-preview.spec.js`, `room.spec.js`, `custom-avatar.spec.js`, `leave-and-return.spec.js`, `share.spec.js`, `room-timers.spec.js`, `language.spec.js`, `accessibility.spec.js`; `docs/testing.md`, если в нём названы перенесённые тесты.
- **Consequences** (`games/consequences/tests/e2e/`): `landing.spec.js`, `site.spec.js`, `not-found.spec.js`, `link-preview.spec.js`, `room.spec.js`, `room-timers.spec.js`, `reading.spec.js`, `accessibility.spec.js`; `docs/testing.md`, если в нём названы перенесённые тесты.
- **Прогон против прода**: те же тесты, на мобильном проекте меньше запросов.
- **Не входит**: тесты, которые есть только в одной игре; Jest-тесты (их чистка сделана отдельно, в `feature/test-duplicates`); код игр и ядра.
