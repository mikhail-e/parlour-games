# Security Policy

## Reporting a vulnerability

Please report security problems privately: open the **Security** tab of this repository and click **Report a vulnerability** ([direct link](https://github.com/mikhail-e/parlour-games/security/advisories/new)). Don't open a public issue for them.

The scope is the code in this repository and the running games: "Who am I?" at https://whoami.escapist.club/ and Consequences at https://story.escapist.club/. Only the latest version of each game, the one in production, is supported.

This is a personal project maintained in spare time: every report is read, but there is no promised response time.

How a game tells its players apart and what its server checks is described in the game's CLAUDE.md ("Who am I?": [How it works → Player identity](games/whoami/CLAUDE.md)); the players of every game are the kit's ([The players of a room](packages/room-kit/CLAUDE.md)).
